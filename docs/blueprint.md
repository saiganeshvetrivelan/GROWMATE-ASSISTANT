# **App Name**: GrowMate

## Core Features:

- Field Mapping: Interactive map for drawing and defining field boundaries.
- Real-Time Data Dashboard: Display real-time sensor data (soil moisture, temperature, humidity) in an easy-to-understand format.
- AI-Powered Irrigation Recommendations: Generate irrigation schedules based on sensor data and weather forecasts, including liters/acre suggestions, using a tool.
- Anomaly Detection: Issue anomaly alerts for sudden deviations in sensor metrics, for example low moisture. The alert message contains the severity and a timestamp.
- GrowMate Assistant: Provide a chatbot assistant that uses a tool to give information to users.
- Task Management: Allow users to set, track and view tasks within a calendar, including alerts
- Voice Assistance: Voice assistance with multilanguage support.

## Style Guidelines:

- Primary color: Forest green (#388E3C), inspired by the lushness of healthy crops. This provides a strong association with growth and nature, and provides good contrast with the chosen dark background.
- Background color: Dark forest green (#0A190A), offering a modern, sophisticated look while maintaining the earth-related theme, with sufficient darkness to allow light-colored elements to pop.
- Accent color: Yellow-green (#9ACD32), analogous to the primary but significantly brighter. This provides highlights and draws attention to key interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern and neutral look. Readable in headings and blocks of text.
- Use clear, minimalist icons to represent data points and actions. Icons should be line-based for a clean and modern aesthetic.
- Employ a modular card-based layout for displaying sensor data, recommendations, and tasks. This provides a clean and organized user experience.
- Incorporate subtle animations to indicate data updates and user interactions. This provides a polished and responsive feel.
